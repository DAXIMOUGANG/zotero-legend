# Zotero 高亮图例条 — Spec

> 状态：**草稿，待确认** ｜ 2026-10-19（v2：加入双屏跟随）
> 词汇以根目录 `GLOSSARY.md` 为准；决策背景见 `docs/adr/0001`、`docs/adr/0002` 与 `docs/research/2026-10-19-zotero-annotation-legend-research.md`。

## 1. 目标

在桌面顶部常驻一条极简的**图例条**，把 Zotero 的 8 种高亮色各显示成一个**圈圈**，让「这条高亮表示什么」在任何时刻都看得见；不读论文时它完全消失。

## 2. 非目标

- 不改 Zotero、不做 Zotero 插件、不读 `zotero.sqlite`（运行时被锁）。
- 不做配色编辑器：改颜色/文案 = 改 `colors.json`。
- 不跟**档位**（A/B/C）联动，固定 8 个圈。
- 不做统计、体检、笔记导出——那是 Obsidian 侧的事。

## 3. 用户可见行为

### 3.1 图例条

- 无边框、无标题栏、背景全透明；始终置顶；不进任务栏、不进 Alt+Tab。
- 出现在 **Zotero 所在的那块屏幕**的顶部水平居中（屏幕判定见 3.2），距该屏顶边 8 逻辑像素。
- 8 个圈按 Zotero 调色板顺序排列：**黄 红 绿 蓝 紫 品红 橙 灰**，与数字键 1–8 对齐。
- 圆直径 18、间距 10（逻辑像素，按所在屏幕的缩放比换算物理像素）。
- 品红是**幽灵圈**：40% 不透明度 + 虚线描边。

### 3.2 显隐与屏幕归属

- 当前**前台窗口**属于 `zotero.exe` 进程时显示；切到别的程序即隐藏。
- 判定按**进程 id**，不按窗口标题——Zotero 的对话框/子窗口也是 Zotero 上下文。
- 本程序自己的气泡与卡片出现时，视为「仍在 Zotero 上下文」，不能因此把图例条藏掉。
- **屏幕归属**：取前台 Zotero 窗口，与各显示器求交集，选**重叠面积最大**的那块屏（窗口跨屏、或只剩一条边可见时也能落到正确的屏）。
- Zotero 被拖到另一块屏后，图例条在 200 ms 内跟着移到那块屏（默认回到该屏顶部居中；若该屏有记住的拖动位置则用记住的位置）。
- 显示器热插拔、分辨率/缩放变化后，下一轮判定自动生效，不需要重启。

### 3.3 悬停

- 鼠标停在某个圈上：该圈放大 1.2 倍，圈**下方**出现自绘**悬停气泡**，内容只有该色的**短义**（4 字）。
- 移开即消失；气泡不越过所在屏幕边缘。

### 3.4 点击

- 点击某个圈：在条下方展开**完整卡片**，三行：短义 / 判定问句 / 落卡栏目。
- 点卡片外任意位置、或再点该圈，卡片关闭。

### 3.5 拖动与位置记忆

- 在圈上按住并移动超过 4 像素 → 整条跟随鼠标移动；松手后位置写入配置。
- 按下后未超过阈值就松开 → 视为点击（走 3.4），不移动。
- **位置按显示器分别记忆**（键 = 显示器的设备名）：主屏拖到哪、副屏拖到哪，各记各的；没拖过的屏用「顶部居中」默认位。

### 3.6 托盘

- 托盘图标右键：`显示图例` / `隐藏图例` / `重新载入配置` / `打开配置文件夹` / `退出`。
- 双击图标 = 显示/隐藏切换。

### 3.7 自启动

- 登录 Windows 时自动启动（启动文件夹快捷方式，由 `install.ps1` 创建，指向 exe）。
- 不开 Zotero 时不显示任何东西，只占后台。

### 3.8 异常

- `colors.json` 缺失或损坏：仍正常启动，用内置默认 8 色，托盘气泡提示一次「配置读取失败，已用默认配色」。
- Zotero 未安装/未运行：图例条永不出现，托盘图标仍在。

## 4. 数据：`colors.json`

```json
{
  "bar": { "anchor": "top-center", "offsetTop": 8, "dotDiameter": 18, "dotGap": 10, "hoverScale": 1.2, "positions": {} },
  "behavior": { "onlyWhenZoteroForeground": true, "pollIntervalMs": 200, "topmostRefreshMs": 3000 },
  "colors": [ ...8 条, 见下表... ]
}
```

`bar.positions` 形如 `{ "\\\\.\\DISPLAY1": {"x": 610, "y": 8}, "\\\\.\\DISPLAY2": {"x": 950, "y": -1072} }`（逻辑坐标，左上角）。

## 5. 技术方案

- **栈**：C# 5 + .NET Framework 4.8 WPF，用本机 `csc.exe` 编译成单个 `.exe`；无 XAML（csc 不编译 BAML），界面全部代码构建。
- **窗口**：`WindowStyle=None` + `AllowsTransparency=true` + `ShowInTaskbar=false` + `Topmost`；`SourceInitialized` 后加 `WS_EX_NOACTIVATE | WS_EX_TOOLWINDOW`。
- **命中**：分层窗口逐像素 alpha → 全透明像素自动点击穿透，圆圈可悬停/点击。**退路**：若实测命中不理想，改用 `SetWindowRgn` 把窗口裁成「8 圆 + 气泡 + 卡片」的并集。
- **前台判定**：`GetForegroundWindow` + `GetWindowThreadProcessId`，与缓存的 zotero 进程 id 集合比对；集合每 2 s 刷新，前台判定 200 ms 一次。
- **屏幕判定**：`MonitorFromWindow(hwndZotero, MONITOR_DEFAULTTONEAREST)` + 各屏 `rcMonitor` 求交面积取最大；显示器枚举用 `EnumDisplayMonitors`。
- **DPI**：PerMonitor V2；用 `GetDpiForMonitor` 取目标屏缩放，逻辑像素 × 缩放 = 物理像素。
- **置顶续命**：每 3 s `SetWindowPos(HWND_TOPMOST)`。
- **托盘**：WinForms `NotifyIcon`。
- **配置**：启动读取；托盘「重新载入配置」热载入。

## 7. 验收判据

1. ✅ 双击 exe：无控制台黑窗（`/target:winexe`）、任务栏无图标（`ShowInTaskbar=false`）；Zotero 在前台时，**Zotero 所在屏**顶部居中显示 8 个圈；切到浏览器 1 s 内消失，切回 1 s 内出现（日志 `visible=True/False` 与实测截图）。
2. ✅ 8 个圆的取色值与上表 hex 完全一致（`measure.ps1` 精确匹配 7 个启用色，直径 18px、圆心间距 28px）；品红表现为虚线幽灵圈。
3. ✅ 悬停任一圆：放大 1.2×，下方气泡显示对应 4 字短义，气泡不出屏（实测「主张」气泡）。
4. ✅ 点击任一圆：卡片三行内容与上表一致；点空白处关闭。
5. ✅ 圆与气泡以外的区域点击可穿透到下面的 Zotero 窗口：`WindowFromPoint` 在圆上返回图例窗 `791244`，在透明边上返回 Zotero 主窗 `201986`。
6. ✅ 把 Zotero 窗口移到另一块屏，图例条随之出现在那块屏顶部居中（日志 15:38:28.967 起从 `\\.\DISPLAY2` 切到 `\\.\DISPLAY1`，<50 ms 完成）；移回原屏后回到记忆位置 `1541,-1072`；每屏位置独立保存（`positions.\\.\DISPLAY2 = {x:990,y:8}`）。
7. ✅ 两屏缩放比不同（主屏 200%、副屏 100%）时，圆均为 18 逻辑像素、视觉等大（物理 36px / 18px），文字清晰不发虚。
8. ⏳ 托盘「退出」代码就绪（未点击实测）；自启快捷方式已用 `install.ps1` 实际创建于启动文件夹（`ZoteroLegend.lnk`），下次登录生效。
9. ✅ 删除 `colors.json` 后启动：程序正常显示内置默认色、不崩溃（托盘气泡提示已接线）。

## 8. 风险与已知限制

- WPF `AllowsTransparency` 会关掉硬件加速：窗口极小，可接受；若文字发虚再调字号/改用位图渲染。
- 全屏独占游戏与 UAC 安全桌面上盖不住——写进使用说明。
- 「仅前台显示」在 Zotero 内部弹对话框时可能有 200 ms 级闪动（按进程 id 判定已把闪动压到最小）。
- 跨屏拖动 Zotero 时图例条会跟着跳屏；若用户希望它原地不动，需要改成「固定在用户拖到的屏」。
- 拖拽与点击的冲突用 4 像素阈值区分。

## 9. 待确认（均已确认）

## 10. 实现记录（2026-10-19）

- 编译：`build.ps1` → `csc.exe`（4.8.4084）+ GAC 里的 WPF 程序集，单文件 30 KB；`/codepage:65001` 让中文注释不进 GBK 坑；PS 脚本本身保持纯 ASCII。
- 三个实测到的坑：①`JavaScriptSerializer` 对数组返回 `object[]` 而非 `List<object>`；②`ParseColor` 只认 6 位 hex，`#AARRGGBB` 会退化成灰（卡片曾整块 128 灰）；③WPF 建窗时先按系统 DPI(192) 渲染、收到 per-monitor DPI 变更后才切到 1.0，首帧会大一圈。
- 对策：首帧先 `Opacity=0`，等窗口宽度等于 `NominalWidth × 目标屏缩放` 再显形；位置由 `SetWindowPos` 按物理像素校正，200 ms 轮询里发现偏移就重放。
- 测试开关：`ZoteroLegend.exe --always` 忽略「仅 Zotero 前台」，用于截图/自动化验证。
