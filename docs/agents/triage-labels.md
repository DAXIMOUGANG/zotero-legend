# Triage 标签

技能用五个固定的 triage 角色说话。本文件把角色映射到本仓库实际使用的标签串。

| mattpocock/skills 中的标签 | 本仓库的标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 待维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 定义充分，可交给 AFK agent |
| `ready-for-human` | `ready-for-human` | 需要人来实现 |
| `wontfix` | `wontfix` | 不处理 |

技能提到某个角色时（例如「打上 AFK-ready 的 triage 标签」），使用本表对应的标签串。

本仓库用本地 Markdown 跟踪器，标签即票文件顶部的 `Status:` 值。改命名时只改「本仓库的标签」这一列。
